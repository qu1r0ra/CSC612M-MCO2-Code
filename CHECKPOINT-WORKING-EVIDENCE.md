On 2026-10-27, on NVIDIA GeForce RTX 5060 (driver 610.88), `uv sync --group dev` and `just build-cuda` succeeded in this course worktree. With `STOQUANT_TEST_CUDA=1`, `uv run pytest --require-cuda tests/test_cuda.py -k 'prescribed_scale_and_words_match_oracle or layer_two_decode_satisfies_fp64_bound or k3_4bit_packing or match_cpu' -q` passed 21 tests (266 deselected). A separate preliminary run used the upstream CUDA binary freshly built at the commit above, normal FP32 input generated by `np.random.default_rng(2026).normal(size=n).astype('<f4')`, seed 123, and one CLI compression per cell. Each GPU record matched the CPU record byte for byte and the CLI decoded the GPU record. Exact invocation: `build/stoquant.exe compress --input input-N.f32 --output cuda-N-B.msq --bits B --seed 123 --backend cuda --timings`; compare with the same command using `--backend cpu` without `--timings`, then `build/stoquant.exe decompress --input cuda-N-B.msq --output decoded-N-B.f32`.

The proposed host-side packing of CUDA-generated codes has not been demonstrated: the current CLI packs on the GPU and decodes on the host. Its deviation and evidence need to be stated in the report.
